> 响应统一为 JSON：`{"code":200,"data":...}`；失败见 `03-错误码与坑.md`。

## 三、预算（每季一次）
- 读：`GET /est/cfo/budgetList` → `deptType(1营销2生产3人力)/thisRoundBudget/currentRoundBudget/currentRoundUse/usageRate`
- 写：`POST /est/cfo/inputBudget?budgetList=<完整3条JSON>`（**参数必须放 query**，postId=4；放 body 会 200 假成功）
- 规则：每部门每季**使用率须 80%–120%**，否则每项扣 1 万分（记在 `integral`，非商誉）
- 顺序：**先写预算 → 再发薪/缴费**（否则发薪报 `600 预算信息获取失败`）
- 临时预算：`POST /est/budget/temporary/apply` → `POST /est/budget/temporary/approve`

## 四、贷款
- `GET /est/cfoLoan/getLoanList` → `{list:[{loanName,loanCash,loanInterest,loanStartTime,loanEndTime}], cashLimit}`
- `POST /est/cfoLoan/saveLoan` body `{loanCode, loanCash, creator}`
  - `DK1` 直接融资 1 季 5%｜`DK2` 短期银行 4 季 10%｜`DK3` 长期银行 8 季 2%/季
  - 额度＝3×权益（`cashLimit`），可叠加；**POST 只发一次**（超时会重复借款）

## 五、费用 / 应付 / 贴现
- 管理费：`GET /est/ruleFee/getFeeList` → `POST /est/cfoAccountsPayment/paymentCash` body `{payCash:1500, feeCode:"1", id:<feeId>, creator}`（postId=4）
- 付应付：`POST /est/dataTradeAccount/updatePayment` body `{id, creator, accountDate:0}`（逐条）
- 贴现：查 `GET /est/dataTradeAccount/getDiscount?paymentData&round`；写 `POST /est/dataTradeAccount/saveDiscount`（报文未完整验证）

## 十、财务报表（年报）
| 用途 | 接口 |
|---|---|
| 提交验证 | `GET /est/cfoReport/checkSubmit?round&teamId` |
| 填报记录 | `GET /est/cfoReport/getData?round&teamId` → `result.left`（学生填，含 `sheetId/costId/profitId`）、`result.right`（系统值）、`submit:"yes/no"` |
| 系统正确值 | `GET /est/cfoReport/getSystemReportData?round&teamId` |
| 保存/提交 | `POST /est/cfoReport/saveData`（59 字段全部 query + 三个 id + `state=1` + `submitState=true`） |
| 报表数据源 | `/est/initBanlanceSheet/getList`、`/est/dataProfit/getList`、`/est/dataCashFlow/getList` |

**限制**：仅年末轮（round 4 / round 8）可录入（否则 500「只有年末才能录入该条数据」）；**提交后不可改**（500「报表已提交,请勿重复操作」）。
**流程**：`getData` 取 id → `getSystemReportData` 取系统值 → `saveData`(submitState=false) 保存 → `saveData`(true) 提交 → 回读 `submit="yes"`。
