# 错误码与坑（实战汇总）

## 一、错误码对照
| code | 含义 / 处理 |
|---|---|
| 200 | 成功。⚠️ **不等于一定落库**（见 §二） |
| 400 | 参数缺失/非法。`msg` 会直接说缺哪个字段（如 `orderCode 不能为null`、`declareNum 不能为null`），逐个补即可 |
| 401 | 登录失效。两种形态：①HTTP 401；②**HTTP 200 + `{"code":401,"msg":"登陆已失效"}`** |
| 500 | 业务失败。看 `msg`：`订货会已结束`、`只有年末才能录入该条数据`、`报表已提交,请勿重复操作`、`缺少当前市场资质`、`未提交报表，请确认其报表已提交`、`系统错误`（多为轮次/岗位不对） |
| 600 | `预算信息获取失败`：本轮还没写预算 → 先写预算再发薪/缴费 |
| 610 | `预算不足`（msg 带所需金额）→ `POST /est/budget/temporary/apply` → `/approve` 加临时额度 |

## 二、"200 假成功"（最坑）
| 接口 | 现象 | 正确做法 |
|---|---|---|
| `POST /est/cfo/inputBudget` | `budgetList` 放 form **body** → 200 但值不变 | **参数放 query**：`?budgetList=<JSON>` |
| `POST /est/cfoReport/saveData` | 同上 | 全部 56/59 字段放 query |
| `POST /est/board/temp/*`（画布临时接口） | 200 但不落库（如绑特性、画布预算、`ruleOrder/apply`） | 用正式接口或界面 |
| 一般写接口 | 200 但回读没变 | 三段式：读前置 → 发一次 → **回读校验**；不变就换方式，绝不连点 |

## 三、超时 / 空响应（POST 绝不自动重试）
- 平台常 30–60s 超时：请求可能已在服务端处理，**重发会重复下单/重复借款**。
- 真实事故：借款 20 万超时后补发 → 两笔合并成 **1 条 40 万贷款**（息 4 万）。
- 正确：POST 只发一次 → 等 30–60s 回读 → 没落库再决定；GET 可重试。

## 四、登录 / 风控
- **平台单会话**：用密码 `/login` 续期会顶掉浏览器会话；浏览器重进又顶掉脚本 → 互踢触发风控（"登录状态一直掉"）。
- 正确：脚本**不登录**，用 `脚本\游戏-取auid.py` 从 Edge 历史最新 `estweb/home?qs=` 提取浏览器 auId；`est_common.auid()` 已内置该策略（`EST_ALLOW_PWD_LOGIN=1` 才允许密码登录）。
- 轮询频率 ≥25s，避免多进程并发刷接口。

## 五、轮次 / 换季
- 只读接口必须带当前 `round`；否则读到历史快照（曾误判现金 298,500）。
- 换季先 `ctx <新round>` 再操作。
- **换季自动结算不固定**：round2→3 自动扣了发薪＋管理费＋到货入库＋自动开产；round3→4 没自动。**每季先回读 `flag/paydayState`，有 flag 才发薪，别重复缴费**。

## 六、窗口类操作（订货会/竞单/广告）
- 老师端开窗，通常**只开 5 分钟**；`getAdvertising` 窗口外返回 `{"code":200,"data":{"code":500,...}}`（嵌套 500，判"开窗"要检查 `data` 是否为市场列表）。
- **必须提前 dry-run**：用已结束轮次订单把 `saveOrder` 全字段试出来（400 无副作用）；窗口内只发一次。
- 申报只走 `POST /est/cooDealerOrderStorage/saveOrder`；`board/temp/market/ruleOrder/apply` 是错误接口。
- 规则：**广告投放多者优先选单** → 先投广告再申报。

## 七、其它已知坑
| 现象 | 原因 / 对策 |
|---|---|
| 派工报「当前产线不存在」/「系统错误」 | `dataEquipmentId` 必须传 `equipmentCode`（不是记录 id）；`levelIds` 是对象数组 JSON；产线 state 必须=2（停产） |
| 招聘画布链 200 但派工选不到人 | 画布链不落库；走正式链 `hrd/recruit/save → hrd/getHrdList → hrd/sendOffer → 等入册` |
| 开产失败 | 别用 `equipmentOpenToProduce`；用 `smart/openSmartProduction` |
| 发薪报「不能解聘在产员工」 | 多为轮次闸门/参数错，先回读 `employeeList.flag` 与 `paydayState` |
| 年报提交不了 | 仅年末轮（round 4/8）可录；提交后不可改 |
| 收货 610 | 生产预算不足（收货按订单金额扣预算）→ 先写预算或临时预算 |
| 评分理解 | `score` 字段=总分×1000，被"数字化建设"放大；正式评价看**权益/经营状况**；`integral`=预算使用率扣分累计（1 万分/项） |
